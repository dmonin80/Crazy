# 0.2.12 — сетевой многопользовательский режим

- Один сервер общей базы, отдельные клиенты через TCP; запуск клиента из общей папки без записи в неё.
- Автоматический выбор сетевого клиента по `network.json` и отдельные BAT запуска сервера/клиента.
- Сервер запускается только по локальному пути; запрещён запуск сервера с UNC-пути или подключённого сетевого диска.
- Автообновление основных таблиц каждые 15 секунд; конкурирующие изменения защищены транзакциями и версиями.
- Настройка и остановка сервера доступны через loopback с локальным ключом управления.
- Сохранены пароли, разрешения, фильтры и прежний формат базы.
- BAT используют pushd для путей UNC. Скрипт сборки добавляет конфигурацию и сетевые команды запуска в дистрибутив.
