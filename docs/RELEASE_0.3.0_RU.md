# Выпуск 0.3.0 — 30 октября 2026

## Изменения

### Надёжность и безопасность

- Блокирующий HTTP вынесен в рабочий поток с модальным индикатором.
  Главное окно продолжает обрабатывать события; повторные команды во время
  запроса блокируются. Закрытие окна во время запроса откладывается до завершения.
- HTTP-клиент переиспользует соединения. Системные прокси не вмешиваются
  в локальное/корпоративное подключение клиента; TLS-проверка не отключается.
- Для команд сохраняется UUID вместе с отпечатком исходных параметров.
  После потери ответа доступна проверка результата; повтор той же команды
  использует прежний UUID, в том числе после перезапуска клиента.
- Добавлены модели валидации основных API-запросов и ограничения импортов.
  Ошибки входных данных не возвращают значения паролей или содержимое файлов.
- Добавлено ограничение частоты входа: до 10 попыток на имя за минуту и общий
  предел 200 попыток; успешный вход сбрасывает счётчик данного имени.
- Хеширование при входе выполняется вне транзакции записи SQLite.
  Просроченные токены удаляются при успешном входе.
- Подключения чтения SQLite явно закрываются. Обзор имущества и остатков
  загружается одним запросом из согласованного снимка базы.
- Из аудита импорта исключены исходные данные Base64; сохраняются SHA-256,
  настройки и результат. Повтор завершённого импорта не создаёт лишнюю копию.
- Проверка резервной копии включает пробное восстановление в отдельную базу.
- При сетевом HTTP показывается предупреждение; добавлены примеры HTTPS.

### Интерфейс

- Исправлена доступность кнопки «Обновить» после входа.
- Основная таблица переведена на QAbstractTableModel/QSortFilterProxyModel.
- Экспорт соответствует порядку строк и отображаемых колонок.
- Добавлены сохранение геометрии колонок, выбор колонок, видимые фильтры,
  удаление отдельного фильтра и именованные наборы фильтров.
- Состояние соединения и время обновления отделены от обычных сообщений.
- Добавлены карточка имущества с QR-кодом и история перемещений.
- Добавлены журнал документов, просмотр состава и печатная форма PDF.
- В инвентаризации объединены сканер, выбор места, фильтры, прогресс,
  ручные отметки, находки и завершение. Завершённые сессии доступны для чтения.
- Сканирование выполняется одним серверным действием с идемпотентностью.
- Импорт содержит указатель этапов и итоговую сводку различий перед проведением.
- Для явного локального режима добавлены `--local` и `start_local.bat`.

## Проверка

Полный набор: **87 тестов прошли**, включая 73 исходных теста и 14 новых
проверок (параметризация даёт отдельные случаи).
Среда: Linux x86_64, Python 3.12.14, PySide6 6.12.0,
FastAPI 0.162.0, uvicorn 0.54.0.
Графические тесты выполнялись с `QT_QPA_PLATFORM=offscreen`.

Проверены исходные сценарии импорта/перемещений, конкурирующие изменения,
дробные количества, права, PDF/QR, запуск/повторный запуск сервера,
первичная настройка через GUI и работа сервера после закрытия клиента.
Дополнительно проверены ошибки API, ограничение входа, компактный аудит,
единственная копия при повторе импорта, сканирование/повтор/закрытая сессия,
пробное восстановление, порядок экспорта, отзывчивость GUI во время I/O,
повтор операции после создания нового окна и новые экраны/печатная форма.

Два предупреждения относятся к совместимости pytest-плагина anyio и
устаревающему адаптеру TestClient/httpx в зависимостях. Проверки проходят;
предупреждения не подавлены.

Снимки интерфейса получены запуском программы с временными примерными данными.
Результаты старых версий в остальных документах сохранены как история.

## Практические пределы

- Windows EXE не собран и не проверен: выпуск содержит исходники и скрипт сборки.
  BAT-файлы требуют проверки на вашем Windows-ПК. Linux-проверка не подтверждает
  работу Windows DLL, принтеров и политик корпоративной сети.
- HTTPS требует реального имени сервера, сертификата и настройки доверия.
- Проверки двух клиентов выполнялись программно; физические ПК и печать
  на реальных принтерах в этой среде не проверялись.
- Фотографии имущества и мобильный/offline-клиент не добавлялись: для них
  нужен отдельный сценарий хранения, синхронизации и резервного копирования.
- SQLite оставлена как существующее хранилище. Нагрузочный предел числа
  одновременно работающих пользователей отдельно не измерялся.
