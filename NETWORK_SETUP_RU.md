# АХО 0.2.12 — одна база, несколько компьютеров

## Как это работает

На основном компьютере работает один сервер. Файл `data/inventory.sqlite3` остаётся в папке программы на локальном диске этого компьютера. Остальные ПК обращаются к серверу по TCP, напрямую SQLite не открывают. Сервер работает после закрытия окна программы, пока включён основной компьютер и не остановлен сервер.

## 1. Подготовка основного компьютера pc00527

1. Закройте прежнюю программу и остановите прежний сервер через меню «Система → Остановить локальный сервер и выйти» либо `stop_inventory.bat`.
2. Сделайте резервную копию всей рабочей папки `data`. Копируйте после остановки сервера.
3. Разместите новую программу на **локальном диске** основного ПК, например `D:\AHO_Server`. Запускайте сервер через этот локальный путь, не через `\\pc00527\...` и не через подключённый сетевой диск.
4. Сохраните прежнюю рабочую папку `data` рядом с программой. При переходе в новую папку перенесите туда `data` после остановки старого сервера. Не запускайте старый сервер после переноса.
5. Для исходников соберите EXE через `build_windows.bat` на Windows с Python 3.14. Затем используйте всю папку `dist\AHO_Inventory` с `_internal`; положите рабочую `data` рядом с EXE. В архиве исходники, готовый Windows EXE здесь не собирался.
6. Запустите **start_network_server.bat**. Сервер слушает TCP-порт **8765**. При новой базе задайте пароль постоянного пользователя «Администратор». Для существующей базы используйте прежний пароль.
7. Под Администратором создайте пользователей и отметьте разрешения кнопкой «Пользователи».

На основном компьютере всегда используйте `start_network_server.bat`. Обычный EXE при наличии `network.json` запускает только сетевой клиент. Если работает сервер другой версии или в локальном режиме, сначала остановите его.

## 2. Доступ через брандмауэр

Разрешите входящие TCP-подключения на порт 8765 на основном ПК для нужных рабочих компьютеров или подсетей. Пример команды PowerShell, выполняемой администратором на сервере для компьютеров его локальной подсети:

```powershell
New-NetFirewallRule -DisplayName "AHO Inventory TCP 8765" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8765 -Profile Domain,Private -RemoteAddress LocalSubnet
```

Если клиенты находятся в других подсетях, укажите их адреса/подсети вместо `LocalSubnet` согласно настройкам вашей сети. Клиентская проверка:

```powershell
Test-NetConnection pc00527 -Port 8765
```

## 3. Общая папка для клиентов

1. В общую папку `\\pc00527\Distr\AHO_Inventory` положите **клиентские файлы**: `AHO_Inventory.exe`, всю `_internal`, `network.json` и `start_network_client.bat`. Файлы берите из новой сборки.
2. Не размещайте в клиентской общей папке рабочую `data`, `local_server.json`, журналы или резервные копии. Они остаются в папке сервера на его локальном диске. Для клиентской папки достаточно прав чтения и запуска.
3. В `network.json` уже задано:

```json
{
  "server_url": "http://pc00527:8765"
}
```

Если имя основного компьютера другое, замените `pc00527` на его DNS-имя или IP-адрес. При копировании клиентов на локальные диски сохраните рядом этот же файл.

4. На рабочих местах запускайте **start_network_client.bat** либо EXE рядом с `network.json`. Клиент не создаёт файлы блокировки, настройки или базу в общей папке.
5. Выберите пользователя, введите пароль. Изменения таблиц подтягиваются автоматически каждые 15 секунд, либо сразу кнопкой «Обновить». Пока открыт диалог, автоматическое обновление приостанавливается.

При недоступности сервера клиент показывает ошибку подключения и не создаёт отдельную базу. Права проверяются сервером, конкурирующие операции выполняются транзакционно. При конфликте обновите таблицу и повторно выберите имущество. Если ответ на проведение документа потерян, не повторяйте операцию вслепую: программа показывает идентификатор запроса для проверки результата.

## Транспорт и обслуживание

Пример конфигурации использует HTTP в локальной сети. Для шифрования соединения разместите HTTPS-прокси перед сервером и задайте его HTTPS-адрес в `server_url`. Для внутреннего центра сертификации можно добавить `ca_file` — путь к доверенному PEM-сертификату (абсолютный или относительно `network.json`). Проверка сертификата не отключается.

Закрытие окна на сервере не выключает фоновый сервер. Для остановки используйте меню «Система» на основном компьютере или `stop_inventory.bat` из его локальной папки. После перезагрузки ПК снова запустите `start_network_server.bat`; автоматическая установка службы не выполняется.

Локальный одиночный режим по-прежнему доступен: уберите `network.json` из отдельной локальной установки. Для сетевой общей базы этот режим не используйте. Служебные операции первоначальной настройки и остановки принимаются только через loopback с локальным ключом управления.

## Проверки выпуска

Проверены единая база с двумя клиентами, конфликт распределения последней единицы, запрет удалённого служебного управления, чтение сетевой конфигурации и отсутствие записи клиентом в каталог дистрибутива. Проведён запуск фонового сервера с сокетом 0.0.0.0:8765 и подключением двух HTTP-клиентов. Фактический запуск EXE из SMB-папки на Windows и сборка PyInstaller в этой среде не выполнялись.
